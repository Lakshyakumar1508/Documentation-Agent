# User Guide: Intelligent Documentation Agent

## 1. Introduction
The **Intelligent Documentation Agent (DocAgent)** is a developer tool that keeps software documentation in sync with active source code, Git changes, and runtime logs. Unlike simple LLM prompt wrappers, DocAgent:
- Parses code deterministically with AST and Tree-sitter parsers.
- Detects API routes, configurations, and function signatures.
- Evaluates breaking changes across Git commits.
- Flags documentation drift and hallucinations before any change is saved.

---

## 2. CLI Usage Guide

### Initializing a Workspace
```bash
docagent init
```
Creates `.docagentignore` with standard ignore rules and prepares the `docs/` folder.

### Analyzing Code Inventory
```bash
docagent analyze
```
Scans all Python and TypeScript/JavaScript source files, printing tables of:
- Discovered HTTP API routes
- Configuration and environment variables
- Exported functions, classes, and methods
- Discovered entry points (`main.py`, `server.ts`, etc.)

### Generating & Updating Documentation
```bash
# Interactive review mode (shows unified diffs and prompts before applying)
docagent generate

# Automatic apply mode (ideal for CI/CD pipelines)
docagent generate --yes
```

### Checking for Documentation Drift
```bash
docagent validate
```
Compares documentation assertions (`README.md`, `docs/*.md`) against source code reality:
- Flags missing symbols or removed functions.
- Flags non-existent or renamed API routes (Critical).
- Flags missing environment variables (Warning).
- Flags obsolete dependencies in installation instructions (Warning).

### Analyzing Execution & CI Logs
```bash
docagent logs /path/to/server.log
```
Clusters stack traces, scrubs credentials, extracts observed runtime facts, and outputs troubleshooting recommendations.

### Continuous Watch Mode
```bash
docagent watch --interval 3
```
Watches for local code edits and alerts immediately if modifications cause documentation drift.

## 3. VS Code Extension Guide

### Installing in VS Code
1. Open the `vscode-extension` directory.
2. Run `npm run build`.
3. In VS Code, press `F5` to open an Extension Development Host window.

### Available Commands
Press `Ctrl+Shift+P` (or `Cmd+Shift+P`) and search for:
- `Documentation Agent: Analyze Project`: Displays discovered routes, symbols, and configs in the Output panel.
- `Documentation Agent: Generate README`: Synthesizes evidence-grounded README and opens the generated file.
- `Documentation Agent: Check Documentation`: Scans workspace for documentation drift and highlights discrepancies.
- `Documentation Agent: Analyze Logs`: Prompts for a log file and displays fingerprinted failure clusters.
- `Documentation Agent: Review Changes`: Interactive review menu to approve or reject proposed updates.

## 4. Evidence Grounding & Review-First Policy
Every proposal generated by DocAgent contains:
1. **Unified Diff**: Clear before/after inspection.
2. **Rationale**: Exact architectural reason why the file was created or updated.
3. **Evidence Anchors**: Direct pointers to source files, line numbers, and symbol definitions.
4. **Zero Overwrite Without Review**: Unless `--yes` or `auto_approve` is explicitly requested, modifications require manual confirmation.
